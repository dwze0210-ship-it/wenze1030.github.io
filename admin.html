Quick Edit

说明：这个页面不是公开后台登录系统，而是一个“快捷入口”。 点击下面按钮后，会跳转到 GitHub。登录你的 GitHub 账号后即可编辑并保存网站内容。

Edit Gallery

修改照片墙标题、地点、时间和说明文字。

Edit CV

更新简历页面、教育经历、项目和技能。

Upload Photos

上传新的照片、头像、背景图或 PDF 简历。

How to Update

  1. 点击上面的编辑入口。
  2. 在 GitHub 页面中修改文字或代码。
  3. 点击 Commit changes 保存。
  4. 等待 1 分钟左右。
  5. 回到网站页面，按 Ctrl + F5 强制刷新。

File Naming Rules

为了避免图片显示不出来，建议文件名保持简单：

背景图：hero-bg.jpg
头像：avatar.jpg
照片墙：photo1.jpg、photo2.jpg、photo3.jpg

注意：GitHub 区分大小写，photo1.JPG 和 photo1.jpg 不是同一个文件名。
