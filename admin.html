How to Write a New Post

  1. 打开 posts/template.html。
  2. 复制里面的全部代码。
  3. 点击上方 New Post。
  4. 把文件名改成类似 posts/my-new-thought.html。
  5. 粘贴模板代码，修改标题、日期和正文。
  6. 保存 Commit changes。
  7. 回到 thoughts.html，给新文章添加一个链接。
文件名建议使用英文小写和横线，例如： posts/auckland-sunset.html、 posts/research-notes.html。 不建议用中文文件名或空格。

File Naming Rules

为了避免图片显示不出来，文件名尽量保持简单：

背景图：hero-bg.jpg
头像：avatar.jpg
照片墙：photo1.jpg、photo2.jpg、photo3.jpg
简历 PDF：Wenze_Du_CV.pdf

GitHub 区分大小写，photo1.JPG 和 photo1.jpg 是不同文件。
